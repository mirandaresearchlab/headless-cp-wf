# How-to guides

Each guide helps you do one task. Each guide starts with `git clone`, so you can begin with any guide. The guides expect that you did the [tutorial](../tutorials/first-run.md).

| Guide | Task |
| --- | --- |
| [Prepare your image folder](format-image-folder.md) | Arrange images with one or more channels, and set `--group_regex` and the channel names |
| [Run on your own computer](run-on-your-computer.md) | Go from `git clone` to a run on your images, on a Mac or a Linux computer with Docker |
| [Run on a Slurm cluster](run-on-hpc.md) | Run the workflow on any Slurm cluster with Apptainer |
| [Run on Berzelius](run-on-berzelius.md) | Run the workflow on the Berzelius cluster (NSC), step by step |
| [Run with rootless Docker](run-with-rootless-docker.md) | Run the workflow on a server where you have no root rights |
| [Use the containers](use-container.md) | Use the all-in-one Docker image, or the CellProfiler image with Apptainer |
| [Change the CellProfiler pipeline](change-pipeline.md) | Use your own pipeline, or change it safely |
| [Troubleshooting](troubleshooting.md) | Find the cause of an error and fix it |
