# Helper script API

This page documents the Python functions of the helper scripts in `bin/`. Each build makes it from their numpy
docstrings: edit the docstrings in the code, not this page. The command-line options of the
scripts are in [Command-line scripts](cli.md).

The scripts run inside the CellProfiler container, which has Python 3.8. They use only the Python standard
library (and CellProfiler, for `patch_cppipe.py`).
