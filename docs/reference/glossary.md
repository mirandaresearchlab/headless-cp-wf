# Glossary

Use these definitions when reading the guides.

| Term | Meaning |
|---|---|
| Plate | One input folder containing microscopy images |
| Well | A position on a plate, such as A02 |
| Site | An imaging position within a well |
| Channel | One image signal, such as DNA fluorescence |
| Acquisition or image set | All channel images for one imaging position |
| Batch | A group of complete image sets from one plate |
| Job or task | One execution of a workflow process |
| Manifest | A CSV listing image files and metadata for a job |
| Contract | JSON facts read from the pipelines and used by later checks |
| Illumination correction | Adjustment for uneven lighting across an image |
| Segmentation | Assignment of pixels to objects |
| Label mask | Image whose pixel values identify objects |
| Feature | A measured value, such as cell area |
| Headless | Running without a graphical window |
| Slurm | Software that schedules cluster jobs |
| Provenance | A record of the inputs and steps that produced a result |
| Resume | Reuse of valid saved tasks when restarting a workflow |
